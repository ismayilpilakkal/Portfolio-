# PORTFOLIO-THEME

A premium, professional, and fully responsive WordPress portfolio theme designed with high-end glassmorphism aesthetics, vibrant floating glows, and interactive layout elements.

## Live Demo
Check out the theme in action here: **[https://ismayilportfolio.site.je/](https://ismayilportfolio.site.je/)**
## Features

- **Glassmorphism Design**: Modern, semi-transparent UI elements with blurred backgrounds and sleek borders.
- **Dark & Light Modes**: Includes a built-in, seamlessly animated dark and light mode toggle.
- **Dynamic Projects**: Uses a Custom Post Type (CPT) for easy management of portfolio projects straight from the WordPress Dashboard.
- **Scroll Animations**: Integrated AOS (Animate On Scroll) library for smooth fade and slide animations as you scroll.
- **Working Contact Form**: Built-in AJAX contact form that automatically sends messages to the admin email address using native WordPress `wp_mail`.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop viewing.
- **Theme Customizer Support**: Easily change your Hero Image, Resume Link, Contact Info, and Social Media links via the WordPress Customizer.

## Installation

1. Download the repository as a `.zip` file.
2. In your WordPress Admin Dashboard, navigate to **Appearance > Themes**.
3. Click **Add New** and then **Upload Theme**.
4. Upload the `.zip` file and click **Install Now**.
5. Once installed, click **Activate**.

## Usage

- **Customizing Info**: Go to **Appearance > Customize > Portfolio Settings** to update your contact information, resume download link, and social media URLs.
- **Adding Projects**: A new **Projects** menu will appear in your WordPress sidebar. Click **Add New** to create your portfolio pieces.
- **Front Page**: By default, the theme uses `front-page.php` to display your portfolio as a dynamic single-page scrolling website. Ensure your WordPress reading settings are set correctly (Your homepage displays > Your latest posts, or assign it properly).

## Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher
